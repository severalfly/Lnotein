# Lnotein

开源 Android **PDF 标注 / 手写笔记**应用 —— 灵感来自 [Notein 一笔记](https://notein.cn/)，
但**以 PDF 批注为核心、工具栏回归简洁可自定义**：导入 PDF 即批，手写、荧光、文本框批注全部矢量保存，导出不糊。

## 功能（v0.2）

- 📑 **PDF 批注（核心）**：导入 PDF 后每页高清渲染（3x），直接在页面上书写标注；标注矢量保存，与 PDF 内容分层
- 📝 **文本框批注**：「文本」工具点击页面任意位置插入可编辑文字批注，点击已有批注可修改/删除，导出 PDF 时写入矢量文字
- ✍️ **手写书写**：压感墨迹、贝塞尔平滑、掌压防误触（触控笔优先，可开关手指绘制）、撤销/重做
- 🖊️ **笔刷**：钢笔、荧光笔（半透明）、激光笔（轨迹淡出）、笔画级橡皮擦
- 📄 **纸张**：A4 空白/横线/方格/点阵 + 无限画布，双指平移缩放，笔刷粗细不随缩放变化；PDF 页自动适配屏幕
- 📚 **文档管理**：笔记本列表（PDF 文档带徽标）、多页面、缩略图面板、加页/删页
- 📑 **导出**：手写标注 + 文本批注矢量叠加导出 PDF
- ⭐ **可定制工具栏**：显示/隐藏任意工具、上下重排、锁定布局（长按工具栏进入设置）

## 构建

要求：JDK 17、Android SDK（compileSdk 34）。

```bash
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

在 Android Studio 中直接打开项目根目录亦可。

## 技术栈

Kotlin + Jetpack Compose（自绘 Canvas 手写引擎），kotlinx-serialization 存储矢量笔迹（JSON，本地文件），
PdfRenderer 导入 / PdfDocument 矢量导出。

## 数据与隐私

所有笔记保存在应用本地目录（`files/notebooks/*.json`），无网络请求、无账号、无追踪。
